## SAP oracle 上限实验设计讨论（用户主导）

- 目标：测 SAP 选样环节上限。每 task 50 epoch 结束后，参考集 = 当前 task 全量训练数据（干净/真标签）+ buffer 中干净样本（true_labels 过滤），绕过 Robust GMM/promotion/reference 门控/安全检查，全量 patch 不采样（layer3 每图 64 patch，layer4 每图 16）。
- 已澄清概念：SAP 不是网络，是对 CNN 权重的投影操作 W'=W·Mrᵀ；ResNet18 唯一线性层是 classifier，其输入经全局平均池化后无空间维度（[N,512]），每图只有 1 个"patch"。
- backbone 确认：Mammoth resnet18 forward = conv1→layer1(64,32²)→layer2(128,16²)→layer3(256,8²)→layer4(512,4²)→avg_pool2d(4)→flatten→classifier(Linear 512→C)。

## SAP 官方仓库关键事实（github.com/sangamesh-kodge/SAP, AAAI 2025）

- Linear(fc) 层激活矩阵：pre=fc 输入（avg_pool 之后 + flatten 后的 [N,512]，与 BN/ReLU 无关，官方明确用 pooling 后）；post=fc 输出 logits。conv 层：pre=conv 输入（上一算子 BN+ReLU 后），post=conv 原始输出（BN/ReLU 前）。
- 默认 projection_location="pre" → post 侧矩阵全置 I，实际只做输入侧投影 W'=W·M_preᵀ（bias 不动）。project_classifier 默认 True 但在 location=pre 下无实际作用。默认 start/end_layer=0 不裁层 → 官方默认全层含 fc 都做输入侧投影（本仓库收窄为 layer3/layer4 十个 conv 是自主决定）。
- sap 模式无阈值截断（eps_threshold=None，select_basis 直通）；importance=α·sval_ratio/((α−1)·sval_ratio+1)；Mr=U diag(imp) Uᵀ。本仓库 eigh(Gram) 实现数学等价。
- 官方 retain/可信样本选择：① 曲率排序逐类低曲率 top-k（retain_samples 默认仅 150）或 ② ground-truth 误标索引掩码（=oracle 路径）。官方本来就有 oracle 版 retain 集——佐证我们 oracle 实验设计合理。
- 官方 scale_coff 网格 1,3,10,30,100（每轮×10）；本仓库 scale=30000 远超官方默认网格。
- 官方是 unlearning 设定（retain+forget 双投影，默认 projection_type 含 I-(Mf-Mi)）；本仓库只做 trusted/retain 侧 Mr 投影（对应官方 projection_type="Mr"）。
- bias 处理：官方默认（location=pre）不碰 bias（数学正确：bias 在输出空间，无输入维度）；仅 post 投影时 b'=M_postᵀb。Mammoth ResNet conv 全 bias=False，全网络仅 classifier 有 bias。官方只 hook/投影 Conv2d 与 Linear（isinstance 显式限定），BN/ReLU/池化直通。

## Oracle SAP 最终方案 v3（待用户批准后实施）

- 投影目标改为**仅 classifier（最终 Linear）**；激活 = 池化后+flatten 的 [N,512]（官方 pre 位置），每图 1 样本；流式 Gram G=ΣFᵀF（512×512）；eigh 全谱软缩放（无截断）；W′=W·Mrᵀ 仅输入侧，bias 不动；提交后更新 past_model_ckpt。
- 参考集 = 当前 task 全量图像（不过滤，投影无标签）+ buffer 中 observed==true 样本（开关可关）。
- 新参数：--sap_oracle_reference(0/1)、--sap_oracle_scale(默认100，勿用30000——512维Gram能量集中，30000近似恒等)、--sap_oracle_buffer_clean_only(默认1)。
- 绕过：GMM/pending/promotion/trajectory（end_epoch 快照也跳过）、reference 门控、安全检查；异常还原权重的工程保护保留。参考集不跨 task 持久化，无需序列化。
- 诊断：参考集前后准确率（纯矩阵 F@Wᵀ vs F@W′ᵀ）、测试集各 task 前后、谱统计、norm ratio。
- 执行：单测 → debug 冒烟 → 4090 单 task scale 预实验 {10,30,100,1000} → CIFAR10 symm20 seed 0 正式，对照 v3(65.15)/DGC/baseline。
- 注意归因：与 v3 相比同时改变参考集与投影层（conv→Linear），解读需谨慎；后续可补"conv+oracle"臂分离变量。
- 已确认：默认协议无逐 epoch eval/最优模型保留（fitting_mode=epochs，eval 在 task 末）；第50 epoch 模型即最终模型。
